# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Developers evaluating Weave.js, an open-source collaborative canvas framework. They try the live demo and read the code to judge whether to build Miro/Figma/Excalidraw/Canva-like tools on it.

## Product Purpose

Weave.js Frontend UI Showcase: a demo app and reference implementation for Weave.js. It shows drawing and manipulating visual elements (shapes, images, groups), real-time collaboration in shared rooms, tools (select, transform, move, erase) and undo/redo with action history. It doubles as a live playground for visual and collaborative features. Success: developers see what Weave.js can do and copy its patterns.

## Positioning

Official Inditex-backed reference frontend for Weave.js; a working collaborative canvas product built on the framework, not a mock.

## Capabilities and Constraints

- Existing codebase in `code/` (React, Vite/Nitro, Tailwind; Next.js named in README). Stack stays as-is.
- Needs the Weave.js backend and an Azure Web PubSub instance for collaboration.

Weave.js name and logo (`images/logo.png`).

## Evidence on Hand

Demo at https://weavejs.cloud.inditex.com/, docs at https://inditextech.github.io/weavejs/latest/main/, screenshot at `images/screenshot.png`. No testimonials or customer evidence; do not fabricate.

## Product Principles

- The demo is the proof: show real framework capability, not simulated behavior.
- Reference quality: UI patterns should be clear and reusable for developers reading the code.
- Collaboration is first-class: presence and shared state are visible, not hidden.
