# Stageshow kit (vendored subset)

The Stage, Window, Facepile and Avatar parts, with what they import, copied
from the stageshow skill's `kit/` (https://github.com/benjitaylor/skills,
MIT, see `LICENSE`). Used by the logged-out home hero demo
(`components/session/session.hero-demo.tsx`).

Only the files that demo reaches are kept; the rest of the kit (phones,
messages, charts, brand marks, and so on) is not vendored. To use more of
it, copy the file and what it imports from the upstream `kit/`.
